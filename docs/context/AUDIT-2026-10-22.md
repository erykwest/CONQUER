## Vocabolario: non confondere un'attività con una feature assente

- **MAIN — nucleo implementato:** il percorso runtime richiesto compare nei sorgenti `main`; non aprire una feature nuova per rifarlo. Si possono aprire *QA*, fix o integrazioni circoscritte.
- **PARZIALE:** codice utilizzabile presente, ma manca una condizione meccanica, una dipendenza o una dimostrazione end-to-end; lavorare sul pezzo mancante.
- **PR OPEN:** implementazione proposta in un ramo diverso da `main`; non accreditare a main finché non è merge.
- **DESIGN/FUTURO:** obiettivo privo di un'implementazione completa dimostrabile sul main.
