The game

A medieval world with consequences.

CONQUER is a simulation-driven strategy project. Its systems are being built incrementally; some features are already testable in the Builder while others are long-term design goals.

01 / Landscape

Read the land

Biomes, relief, rivers and forests form the context in which settlements emerge. The environment is a constraint, not a painted background.

02 / Settlement

Build and grow

Found a village, define roads and develop its fabric. The Builder prototype provides a persistent local construction playground.

03 / Fortification

Design a castle

Walls, gates, towers and functional sections form structures you can plan and inspect from the same simulation.

In active development

From settlement to stronghold.

Production, social classes, military response and persistent sieges are evolving systems. They are not all guaranteed to be complete in the public prototype.

Read development notes

Prototype status

The current browser experience is a developmental Builder, not the full planned kingdom and multiplayer simulation.
